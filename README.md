# NT2 - Trabajo Práctico Nº1

## 🧩 Consigna

**Pre-requisitos:** Tener una cuenta en GitHub.

### Pasos a realizar:
1. Crear un repositorio propio en GitHub para este ejercicio.  
2. Clonar el proyecto base desde el repositorio:  
   👉 https://github.com/danielsanchez68/nt2-ejercicio1.git  
3. En la carpeta local del proyecto clonado, eliminar la carpeta `.git` para desvincularlo del repositorio original.  
4. Inicializar un nuevo repositorio Git (`git init`) y asociarlo con el repositorio remoto creado en tu cuenta de GitHub.  
5. Agregar al arreglo `Personas[]` los datos personales del alumno:  
   - Nombre  
   - Apellido  
   - DNI  
   - Email  
6. Realizar un commit con un mensaje descriptivo que incluya nombre y apellido.  
7. Subir los cambios (push) al repositorio remoto en GitHub.
